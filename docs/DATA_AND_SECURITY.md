# 日志、数据与安全边界

日志支持受控项目内的代码观察与可验证区间的回放。它不能证明完整学习过程，也不能证明现实操作者身份；只有实际收到并确认的内容属于已观察事实。

## 存储与查看

默认日志目录为 `<projectRoot>/.student-ide/`：

| 位置 | 内容 |
| --- | --- |
| `events.jsonl` | 追加式原始事件批次；非空行含 `events` 数组与批次校验和 |
| `runs/<id>/` | 一次学生运行的源码快照与独立编译输出 |
| `language-checks/<id>/` | 语言独立验证样例与结果目录 |
| `trash/<id>/files/` | 学生确认回收的原磁盘文件 |
| `trash/<id>/draft.txt`, `record.json` | 已确认的未保存草稿与回收元数据 |

浏览器保存待补传队列/草稿；清理浏览器存储可能丢失未确认内容。不要擅自清空队列、日志、快照或回收区。

UI“过程”显示最近 60 条，导出含日志、覆盖说明和缺口；“回放”显示所选文件历史。MCP 分页最多 500 条，继续读取必须使用**最后一条实际返回事件的 `seq`**，不能直接跳到响应中代表全日志末尾的 `seq`。快照只保留最近十次运行汇总，其他运行仍可从事件查找。

## 事件模型

事件包含 `id`、`sessionId`、全局 `seq`、`type`、`source`、`originChannel`、客户端/接收时间和 `payload`。服务为新事件设置来源通道，不信任浏览器自报操作者。

| 类别 | 已收集内容 |
| --- | --- |
| 文本 | `document.open/snapshot/edit` 的初始内容、增量、文档实例与版本；撤销/重做标记、多光标范围、内容哈希与磁盘基线 |
| 编辑状态 | 选区/光标、可见范围、焦点/失焦、粘贴、组合输入、页面可见性；不是所有原始按键 |
| 文件 | 新建、保存、回收、已打开文件的外部磁盘变化；外部修改者未知 |
| 诊断 | `diagnostics.updated` 的检查状态、版本/哈希、依赖策略、消息和位置 |
| 执行 | 开始、编译/执行阶段、完成、入口/依赖哈希、输出/退出状态/截断/耗时 |
| 环境与阶段 | 语言注册/验证、`session.phase`、采集暂停/恢复/敏感阻断、固定操作的策略拒绝 |
| Codex | 实际收到的 Hook 类型、有限长度的提问/结束回复、工具名与宿主提供的 `toolUseId`；不记录完整工具参数/响应 |

原始日志与推断、人工评价分开保存，不能覆盖事件。每个非空行是批次，不是一行一个事件；确认前先落盘。损坏尾部、版本链中断和暂停区间以 `gaps` 标记并保留原文件。校验和用于发现不一致，不能阻止拥有本机文件权限的人重新写入日志并重算校验和。

## 具体修改如何读取

先检查 `get_editor_snapshot` 的 `recording`、`lastClientAt`、活动模型/版本/哈希、`dirty`、`blocked` 与 `gaps`。当前快照不是所有磁盘文件，也不是浏览器尚未发送的最新输入。

找出目标 `document.edit`，分别调用 `replay_document` 回放该事件前一个序号与事件序号，比较内容。偏移使用 UTF-16，不是 UTF-8 字节；一次事件可替换多个范围。模型刷新可能重置版本，必须结合 `sessionId/path/modelId/version/seq`，不能单独比较两个文档实例的版本号。

## 归因与学习过程限制

`ui_endpoint`、`agent_endpoint`、`hook_endpoint`、`runner`、`language_service`、`external_unknown`、`system` 表示服务入口或组件。它们不证明是谁操作；历史缺少 `originChannel` 的事件保持原样，标为来源未核实。即使约定 Agent 只读，仍不能由一条 UI 事件证明学生本人输入。

未打开文件、IDE 外活动、口头讨论、阅读理解、线下思考、未收到的 Hook、离线未补传、暂停、敏感阻断和超限内容都可能不在日志内。焦点变化不证明分心、停顿不证明不会、大量粘贴不证明使用 AI、绿色退出码不证明理解。完整代码轨迹也不等于完整学习过程。

## 权限与执行

服务监听 loopback；同源检查、路径约束、写入租约、版本冲突和阶段限制用于减少误用。MCP 标记不是身份认证，拥有同用户宿主权限的 Agent 或程序仍可能通过文件/shell/浏览器绕过。强制宿主隔离、身份认证、防篡改审计和补丁提案审批未实现。

解释器/编译器本机执行，运行快照不是沙箱。学生代码可能访问本机或网络；超时终止和环境变量白名单不提供恶意代码隔离。需要不可信代码执行时，应先设计并验收独立隔离环境，不能把本原型宣称为生产考试系统。

## 隐私与上限

采集只覆盖明确项目，UI 显示范围和采集开关。常见凭据检测阻断部分内容，但不保证识别所有秘密；实验项目不得包含凭据。运行日志可能包含完整源码、输出和工具链绝对路径，导出前按实际授权审阅。源码仓库忽略 `.student-ide/`、构建目录、运行产物、`.env` 与开发依赖；打包只选源码/当前清单，不读取学生目录。

插件的日志存储和分析服务在本机；MCP 读取结果会进入调用 Agent 的上下文，导出会生成数据副本。宿主是否向模型服务或同步服务发送这些内容由宿主与调用者策略决定，不能将“本地保存日志”表述为“代码绝不离开本机”。

当前读取单文件上限 250000 字节、缓冲区上限 250000 UTF-16 单位、请求体 2 MiB、文件遍历最多五层、源码集最多 200 文件 / 1 MiB、服务日志恢复上限 100 MiB。Hook 提问/回复最多 20000 字符，页面提问上下文最多 6000 字符，输出每路最多 64000 字符。截断和未知状态必须报告，不能声称覆盖全部对话。

删除数据、修改密钥/`.env`/CI、迁移数据或公开发布仍需遵守[仓库规范](../AGENTS.md)。日志、学生答案与本地安装配置不随源码提交；不要以“环境恢复”为由自动清空证据。
